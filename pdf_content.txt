Flutter
Framework open-source dari Google (2018) menggunakan bahasa Dart. Dapat digunakan untuk
membuat aplikasi multiplatform dengan satu codebase.
Cara kerja:
ΓùÅ Dart dikompilasi ke kode native ARM

Jenis widget Flutter
StatelessWidget ΓÇö tidak punya lifecycle
Hanya punya satu method: build(). Dipanggil
sekali, selesai. Tidak bisa berubah setelah
ditampilkan. Tidak ada yang perlu di-manage.
StatefulWidget ΓÇö punya lifecycle
StatefulWidget terdiri dari dua kelas yang
StatefulWidget adalah konfigurasi yang bersifat
bekerja berpasangan. StatefulWidget dan State.
immutable. State adalah yang menyimpan data dan
punya lifecycle.
Lifecycle widget Flutter
initState() ΓåÆ inisialisasi, fetch data pertama kali
build() ΓåÆ dipanggil setiap ada perubahan state
dispose() ΓåÆ bersihkan controller, cancel subscription
Lifecycle widget Flutter
Flutter sering membuat ulang objek widget dalam jumlah besar. Setiap kali build()
dipanggil di parent, widget-widget child bisa dibuat ulang sebagai objek baru.
Kalau widget menyimpan state-nya sendiri, state itu akan hilang setiap kali widget
dibuat ulang.
Dengan memisahkan widget (konfigurasi, sering dibuat ulang) dari State (data,
dipertahankan selama widget hidup), Flutter bisa melakukan rebuild yang cepat
tanpa kehilangan data yang sedang aktif.

Pengembangan Aplikasi Berbasis Platform
Tugas 2 Individu
Topik : Implementasi Teknik Pengembangan pada Platform Web
Deadline : Sabtu, 25 April 2026 @ 23:59
Deskripsi Tugas
Mahasiswa diminta untuk merancang dan mengimplementasikan sebuah aplikasi mobile
sederhana menggunakan Flutter yang terhubung dengan REST API yang telah dibuat pada
UTS. Proyek ini bertujuan untuk menguji pemahaman konseptual serta keterampilan praktis
mahasiswa dalam pengembangan aplikasi mobile berbasis Flutter, integrasi dengan backend
milik sendiri, autentikasi menggunakan JWT, pengelolaan state secara reaktif, dan navigasi
antar halaman.
Tujuan Pembelajaran
Melalui tugas ini, mahasiswa diharapkan mampu:
ΓùÅ Memahami dan mengimplementasikan layered architecture pada aplikasi mobile
(Models, Services, Providers, Screens, Widgets).
ΓùÅ Mengintegrasikan REST API yang telah dikembangkan sendiri ke dalam aplikasi
Flutter menggunakan HTTP request dan parsing JSON.
ΓùÅ Mengimplementasikan alur autentikasi berbasis JWT, mulai dari login, penyimpanan
token, hingga pengiriman token pada setiap request yang membutuhkan otorisasi.
ΓùÅ Mengelola state aplikasi secara reaktif.
ΓùÅ Menerapkan navigasi antar halaman.
ΓùÅ Menerapkan praktik pengembangan perangkat lunak yang baik (struktur kode,
modularitas, dan dokumentasi).
ΓùÅ Mengkomunikasikan proses teknis secara sistematis melalui demonstrasi.
Ketentuan
Aplikasi yang dibuat harus memenuhi persyaratan berikut:
1. Direkomendasikan menggunakan Flutter sebagai framework utama. Platform tujuan
minimal perangkat mobile dengan sistem operasi Android.
2. Sumber Data (Wajib)
a. Menggunakan REST API yang telah dibuat pada UTS sebagai backend
aplikasi. Perhitungkan implementasi JWT saat berkomunikasi dengan API.
b. Cukup read data saja.
c. Jika hasil pekerjaan UTS Anda tidak memungkinkan untuk digunakan,
silakan buat ulang atau perbaiki backend sesuai dengan ketentuan UTS.
3. State Management (Wajib)
a. Gunakan Provider sebagai solusi state management utama.
b. Mengimplementasikan three-state UI: loading, error, dan data berhasil
ditampilkan.
4. Fitur Tambahan (Opsional). Mahasiswa dapat menambahkan fitur untuk
meningkatkan kualitas aplikasi, seperti:
a. Operasi CRUD lengkap (tambah, ubah, hapus data melalui API)
b. UI/UX enhancement dan responsive layout
c. Fitur pencarian atau filter data
d. Animasi dan transisi halaman
5. Version Control (Opsional)
a. Menggunakan Git untuk version control.
b. Repository diunggah ke GitHub dengan riwayat commit yang jelas dan
deskriptif.
Deliverables
Dokumen teknis dan video demonstrasi dengan durasi 4-7 menit. Jelaskan apa yang Anda
buat dan pengaruh fitur yang Anda tambahkan terhadap aplikasi, baik itu performa atau User
Experience (UX). Kumpulkan di https://forms.gle/1rDPQqZ7CBCz4Zsh6.
